# golf-impact

`ClubDelivery + Club + Lie → LaunchConditions`: an empirical D-plane model (smash factor, launch from spin loft,
start direction mostly from the face, spin axis from face-to-path, gear effect, lie factors).

- Model: [impact.md](../../docs/models/impact.md).
- Club table: `data/clubs/standard.v1.json` (lofts, lengths and the fitted coefficients).
- Closed form, no course access except the lie passed in.

**Depends on:** `golf-core`. **Status:** scaffold (M0); M4.
