Ground Lab

The GolfPhysics ground model (M3) on shaped terrain: crests, a hollow, a drop, a steep face, a cross slope, tour wedges and a backstop. Each tab says what physics predicts, then plays it. Distances in metres; side views stretch height so slopes are readable, and print the stretch.

Built by cargo run --release -p golf-lab -- ground-lab from data/materials/physics.v1.json. Each scenario runs the engine itself (golf-ground) on an analytic terrain.
